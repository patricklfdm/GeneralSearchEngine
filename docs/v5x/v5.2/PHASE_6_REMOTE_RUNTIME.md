All workers are reaped before collection, with original failures and close errors
retained separately.

The five modes each keep 11 public reads and three updates. Sampling uses the
existing short driver markers. These histories are readiness integration; they
cannot substitute for M01's 180-second offered program.

existing semantic negatives. A supplied private-address topology alone cannot
qualify cloud hosts: this entry explicitly accepts `local-no-gcp` only and keeps
