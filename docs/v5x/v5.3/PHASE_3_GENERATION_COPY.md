## Why the complete generation matters

An automatically recovered voter must eventually reclaim its old generation before
another activation can use that slot. The governing floor requires original,
complete generation copies from a real current majority. A source packet and image
alone omit the original promise, selection, selected sources, publication coverage
and possible adoption or accepted-tail records.

The existing read-only transfer service now has a derived current-generation lookup
alias. It serves the actual selected manifest and every exact member through the
existing bounded CHUNK/TRANSFER_COMMIT protocol. Generation replacement, owner
closure and original deadlines still revoke the export. There is no new wire frame,
persisted format, resource cap or retry allowance.

The receiver binds the copy to the same actual peer, root, discovered cut, complete
prefix receive, original guard and deadline. It checks every declared path, size,
digest and the complete inventory before deriving a floor-copy observation. That
observation describes this contacted owner's generation only; copied historical
ACCEPT/PROOF/ACK records do not become new voting observations.

A private completed-copy capability also authenticates the generation's exact
first/current publication coverage. This is required after stable-range compaction:
generic prefix verification alone does not establish those hidden original proofs.
The same structural coverage checks apply to local and network copies.
