# Phase 3 — reservation-scoped learner first contact

Status: ROOT acquisition locally qualified. Complete learner admission, catch-up,
joint voting and Phase 3 remain OPEN.

## Boundary

A joining node initially knows only the operator's root, complete change request
and permanent identity. It cannot fabricate a local voter generation to contact
the group. The private contact transport opens no listener and cannot send voting
or service controls. Its routes are untrusted operator contact addresses.

The native serving owner resolves a sender only from its independently verified
current catalog. An exact active pre-joint ADD/REPLACE reservation permits a small
ROOT transfer using the [A12 lookup alias](PHASE_3_CONTRACT_AMENDMENTS.md#a12--reservation-scoped-first-contact-root-discovery).
The alias binds the complete original request and learner identity. ROOT transfer
shares the existing six-export registry, request capacity and original deadline.
It neither allocates a ballot nor grants, votes, creates learner directories or
returns public readiness. Generation replacement revokes an existing borrow;
cancelled reservations cannot start another transfer. At most three identical
attempts are allowed, with permanent failures stopping immediately.

The receiver verifies both distinct digests: the complete ROOT frame hash and
the embedded root checksum. Group/history identity and the resource contract
must also match. Ordinary complete source packets already include ROOT; this
change supplies the missing first-contact route, not a new source packet format.

steps must acquire and verify the complete live reservation, original generation
and retained ancestry; force an exact admission plan before creating local stores;
materialize the matching preparation revision and original image; return its
receipt; and force the complete matching INTENT before enabling joint voting.
All five ADD/REPLACE profiles and the two REMOVE profiles remain required, as do
automatic elections/adoption, maximum combined headroom and Phase 3 closure.

Public learner factories stay disabled. These results are local component
qualification, not protected CI, a complete network-fault matrix or cloud evidence.
