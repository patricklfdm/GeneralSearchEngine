# Process recovery of context-backed generation reuse

Phase 2 remains **OPEN**. This qualification connects real process death to
[selected slot reuse and intermediate retirement](PHASE_2_CONTEXT_INSTALLATION.md).
It complements the separate [obsolete source process gate](PHASE_2_CONTEXT_INSTALLED_SOURCE_PROCESS.md).

The producer executes the actual three-owner retained-context lifetime, then uses
its selected/installed ballot-22 states. Each installation worker obtains its
three selected sources from actual local journal owners. No supplied reference
is promoted into an ownership receipt. Historical bootstrap observations remain
explicit fixture inputs. Peer stores are checked unchanged by independent replay.

Fifteen installation positions include a second metadata-member write. Twenty-seven
retirement positions include second deletions of original and saved members. Both
halt and externally delivered SIGKILL run at each position, producing 84 cases,
252 workload worker processes and 42 separate live-lock probes. Every case stops
again during a fresh open's context-source force before any installation or vote
response can return.

The final worker completes only the original selected installation, with all
candidate files and the selector checked against the original inputs. Exact
installation retries return the same manifest. It retires only the floor-covered
intermediate generation, retains the original ballot-20 vote, then forces the
ballot-22 successor before releasing context and floor copies. Duplicate retirement
and acceptance are checked. All storage callbacks enforce the existing reservation
bounds, including seven application images, with no reservation leak after close.

Independent replay first validates the complete actual seed lifetime, then derives
candidate/selector prefixes, original/saved retirement inventories, both interrupted
physical states, force order and explicit response boundaries. Twenty mutations
must fail for their intended reason; normal, optimized and relocated executions
must agree. The [evidence index](phase2-evidence/context-generation-process.json)
retains raw evidence and source/build provenance.

This is small-image local process qualification, not power loss, network installation,
or a claim that every filesystem schedule has been covered. Mixed ACCEPT ballots
for the same ENTRY, maximal storage, admitted-bootstrap lifetime and complete
prescribed old/joint/new profiles remain separate closure obligations. No production
Java, format, frozen resource limit, POM or workflow changes are made by this batch.
Public online membership remains disabled.
