## Limits

This is one clean three-voter local integration with complete old certificates.
It is not a distributed election, process-death/power-loss qualification or a
replacement for other supported size/authority profiles. The initial bootstrap
and earlier historical observations still use the declared conditional fixture;
typed image semantics are checked by the Java/core producer, not by Python.
Later campaigns while an old context remains fenced, full bounded transferred
lifetime, maximal resources and old/joint/new coordinated qualification remain
open. Online membership remains disabled.
