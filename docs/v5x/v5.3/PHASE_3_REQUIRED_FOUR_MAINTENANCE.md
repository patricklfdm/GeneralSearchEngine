selected by this reader. Original source-retirement captures bind the pin to the

un-pinned profiles retain their previous expected sequence. Temporal pinned-floor
counts must match the preceding independent physical derivation.

of the five pin force/release callbacks. Qualification validates the original
first, allows only event/wire mutation, and requires the original network/content/
control prerequisite before the intended maintenance rejection. Missing targets,
accepted mutations, changed physical files or unrelated errors fail the entry.
